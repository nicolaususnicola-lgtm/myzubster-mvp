# Contribuire a myzubster-mvp

Grazie per voler contribuire!

## Come contribuire

1. Fork del repository
2. Crea un branch: git checkout -b feature/nome-feature
3. Fai le modifiche e testa
4. Commit: git commit -m "Aggiunge feature X"
5. Push: git push origin feature/nome-feature
6. Apri una Pull Request

## Linee guida commit

- Messaggi chiari e concisi
- Test inclusi per nuove funzionalità
- Documentazione aggiornata
- Rispetta lo stile del codice esistente

## Segnalazione bug/idee

Apri una issue con:
- Descrizione del problema/idea
- Passi per riprodurre (se bug)
- Ambiente (OS, versione software)
