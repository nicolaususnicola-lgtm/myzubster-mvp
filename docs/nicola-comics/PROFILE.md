**Roadmap coordination:** https://github.com/MyZubster-Ecosystem/myzubster/issues/1052

## Obiettivo

Costruire un micro-progetto creativo e software collegato a MyZubster in cui Nicola possa:

- pubblicare fumetti e storie visuali;
- collegare ogni opera a provenienza, autore e stato;
- selezionare alcuni lavori come `NFT_CANDIDATE`;
- creare successivamente un proof NFT verificabile;
- usare Zorgax come guida del percorso;
- collegare il progetto al Marketplace solo dopo la validazione del proof.

## Percorso

**Nicola → fumetto → provenienza → MyZubster → Zorgax → NFT proof → Marketplace → community**

## Stato minimo del pilot

Il progetto potrà essere marcato `PILOT` quando saranno disponibili:

1. un profilo pubblico di Nicola;
2. almeno tre fumetti registrati;
3. un fumetto con proof NFT verificabile;
4. una galleria pubblica;
5. un percorso Zorgax funzionante;
6. feedback reale di Nicola.

## NFT boundary

Un'opera resta `NFT_CANDIDATE` finché non esistono prove on-chain verificabili. Lo stato `MINTED` richiede almeno:

- network/chain;
- contract address;
- token ID;
- transaction hash verificabile.

Non devono mai essere pubblicate seed phrase o private key.
