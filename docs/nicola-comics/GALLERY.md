## Regole della galleria

Ogni fumetto deve avere:

- `comic_id`
- titolo
- serie/episodio
- autore
- descrizione
- file o URL dell'opera
- provenienza/hash quando disponibile
- stato diritti
- stato NFT
- eventuale network/contract/token/transaction hash solo se verificati
